Figranium is an open-source, self-hosted platform for visually authoring reliable browser automation. Create a Task once with blocks, variables, control flow, extraction, JavaScript, and browser state—then reuse that same Task wherever you need it.

- **Visual Task builder** — model browser workflows without beginning from a blank script.
- **Deterministic execution** — invoke saved Tasks through a REST API, official SDKs, schedules, or workflow platforms.
- **MCP for AI agents** — give Codex, Claude, Cursor, Copilot, and other MCP clients access to the browser tools you have already defined.
- **Built for real workflows** — structured results, persistent Cookie States, scoped API keys, 1Password Vault support, proxies, Cabinets, and execution history.
- **Integrations** — use Figranium with n8n, Zapier, Make, Dify, Activepieces, and any application that can call an API.
